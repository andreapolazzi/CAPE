# Codon Optimization Module

Optimizes coding sequences for expression in the target chassis organism and prevents the formation of illegal sites (e.g. restriction sites) decided by the user.

## Input

- .faa file of protein sequences
- Host organism name or codon usage table

## Output

- Codon-optimized DNA sequences (.fna)
